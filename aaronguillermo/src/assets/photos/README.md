# Portfolio photos

Replace `profile.png` with your own portrait, keeping the same filename. A square image at least 600 × 600 pixels works best. The image is imported in `components/ProfilePhoto.tsx`; update that import if you prefer JPG or WebP.

Keep additional portfolio photos in this folder and import them from the component that uses them.

The local .gitattributes keeps photos out of Git LFS so Vercel receives actual image files. Commit the replaced photo alongside your source changes before deploying.
